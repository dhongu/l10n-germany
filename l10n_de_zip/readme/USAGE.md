1. As an administrator, open **Contacts → Configuration → Localization → Cities** and search
   for a postal code: the German localities of that postal code are listed with their federal state.

   ![Cities list filtered on the postal code 01067: the localities Dresden, Dresden Friedrichstadt, Dresden Innere Altstadt, all of the state Sachsen (DE)](static/description/en/01_lista_localitati_cap.png)

2. Open a German contact and type the postal code in the address: the city and the region are
   filled in.

   ![Contact in Germany: the postal code 01069 fills in the city Dresden and the state Sachsen (DE)](static/description/en/02_partener_cap_unic.png)

3. When the postal code is shared by several localities, only the region is filled in; choose the
   city from the list (type the postal code or the name in the city field).

   ![Contact in Germany: the postal code 01067 fills in the state Sachsen (DE); the city field lists the localities of 01067](static/description/en/03_partener_cap_comun.png)

4. To complete existing or imported contacts, select them in the list and run
   *Actions → Germany: set city from ZIP*.

   ![Contacts list with German contacts selected and the Actions menu open on Germany: set city from ZIP](static/description/en/04_actiune_contacte_existente.png)

   ![Contact Customer Dresden after the action: ZIP 01067, city Dresden (01067) and state Sachsen (DE)](static/description/en/05_contact_dupa_actiune.png)
